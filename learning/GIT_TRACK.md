# Git — Parallel Track

Git is taught in small daily doses alongside the main Python/Playwright/API curriculum, always using this repo's real history as the practice ground. Each day ends with an actual commit + push, so this list doubles as a log of what you've actually used.

## Done (Week 1, Day 1)
- `git init` — turn a folder into a repo
- `git add .` — stage all changes
- `git commit -m "..."` — save a snapshot with a message
- `git remote add origin <url>` — link to GitHub
- `git branch -M main` — rename/set default branch
- `git push -u origin main` — upload + link local branch to remote

## Coming up
- Day 2: `git status`, `git diff`, `git log`, undoing an uncommitted change (`git restore`)
- Day 3-4: `.gitignore` rules in depth, unstaging (`git restore --staged`), amending a commit
- Week 2: branching (`git branch`, `git checkout -b`), merging, your first merge conflict (created on purpose so you see one safely)
- Week 9 (per the roadmap): pull requests, code review etiquette, rebase vs merge, resolving real conflicts, commit hygiene at a team level
